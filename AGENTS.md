# Мониторинг сайтов группы
React 19, TypeScript, Vite 8, react-router 8. Тесты — Vitest и Testing Library (не Jest).
## Как работать
- Изменения в файлы вносишь инструментами правки (edit_existing_file, create_new_file), а не кодом в ответе.
- Перед правкой читаешь файл целиком.
- После правок запускаешь `npm run lint -- --deny-warnings` и `CI=true npm test` и исправляешь ошибки.
- В конце коротко перечисляешь, какие файлы изменены и что проверено.
## Правила кода
- Компоненты — функции; хуки вызываются в начале компонента, до любого return.
- То, что вычисляется из данных, не хранится в состоянии и не копируется через useEffect.
- Адрес страницы сайта — `/site/:id`; карточки — ссылки `Link`.
- Тексты интерфейса — на русском языке.
- У полей ввода есть `<label>`; не заменять подписи атрибутом aria-label.
- Тесты лежат рядом с файлом: `*.test.tsx`; данные передаются через `MonitoringContext` и `MemoryRouter`, как в существующих тестах.
